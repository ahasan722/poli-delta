# Bangladesh 64 districts (ADM2) polygons

1. `bbs2022_districts_simplified.geojson` (64 MultiPolygons, EPSG:4326, 1.2 MB). Attributes: geo_code, division_code, division_name, district_code, district_name (BBS 2022 spellings: Chattogram, Cumilla, Barishal, Jashore, Bogura, Chapainababganj, Jhalokati, Netrakona), total_pop, total_male, total_female, sex_ratio, hh_size, enumerated_hh, total_nrb (non-resident Bangladeshis), area_km2 (computed from the unsimplified geometry in EPSG:6933), pop_density_km2.
   - Repo: https://github.com/justinelliotmeyers/bangladesh_2022_census_gis (commit c4e06d4, 2023-09-18), file `district.zip` -> `district.gpkg` (layer `district`). No licence or README in the repo.
   - Original source: Bangladesh Bureau of Statistics, Population and Housing Census 2022 GIS layers (census enumeration geodatabase; attribute LAST_UPDATE_TIME 21-May-2023), as downloaded from the BBS census GIS portal by the repo owner. Population figures are the census GIS portal counts (sum 165,498,422), which differ slightly from the BBS preliminary report (165,158,616) and the PES-adjusted total (169.8 million).
   - What was done: kept 12 attribute columns, simplified with shapely (tolerance 0.0005 deg, topology preserved), 5-decimal coordinates, saved as GeoJSON with geopandas. All geometries valid.
2. `geoboundaries_BGD_ADM2_simplified.geojson` (64 features, 0.9 MB): geoBoundaries gbOpen BGD ADM2 simplified release, fetched from https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/main/releaseData/gbOpen/BGD/ADM2/geoBoundaries-BGD-ADM2_simplified.geojson (Git LFS object, main branch, 2026-10-26). Licence CC BY 4.0, attribution "geoBoundaries (Runfola et al. 2020)". Properties shapeName, shapeISO, shapeID, shapeGroup, shapeType. Re-saved unchanged apart from 5-decimal coordinates. Same lineage as the ADM1 file already in `raw/adm1.geojson`.

Not used: `ifahimreza/bangladesh-geojson` (upazila level only, no district polygons), `Bangladesh-geojson_project/BD_Districts.json` (43 MB, unknown lineage), `mkim2019/bangladesh_inland_water_transport` bgd_districts shapefile (17 MB, HDX 2015 boundaries), `cran/bangladesh` .rda files (need R).
